## Healthcare Analytics Dashboard – Power BI

### Project Overview

Developed a comprehensive **Healthcare Analytics Dashboard using Microsoft Power BI** to analyze healthcare-related data and present meaningful insights through interactive visualizations. The project focuses on transforming raw healthcare data into an easy-to-understand dashboard that helps users identify important trends, patterns, and key performance indicators.

### Objectives

* Analyze healthcare data and identify important trends.
* Create an interactive dashboard for better data understanding.
* Track important healthcare-related KPIs and metrics.
* Present data using charts, graphs, tables, and interactive visuals.
* Enable users to filter and explore data based on different categories.
* Convert raw data into meaningful and actionable insights.

### Data Cleaning & Transformation

Used **Power Query** to prepare the raw dataset before creating the dashboard. The data preparation process included:

* Removing duplicate records.
* Handling missing and blank values.
* Correcting data types.
* Cleaning and formatting columns.
* Transforming data into a suitable structure.
* Checking data consistency and accuracy.

### Dashboard Development

Created an interactive Power BI dashboard containing:

* **KPI cards** for important healthcare metrics.
* **Charts and graphs** for visual analysis.
* **Slicers and filters** for interactive data exploration.
* Category-wise and trend-based analysis.
* Summary tables for detailed information.
* Interactive visuals to compare different healthcare metrics.

### Power BI & DAX

Used **Power BI** for dashboard development and **DAX** for creating calculated measures and KPIs. Applied appropriate visualizations to make complex healthcare data easier to understand and interpret.

### Key Features

* Interactive healthcare data analysis.
* KPI-based performance tracking.
* Trend analysis.
* Category-wise analysis.
* Dynamic filters and slicers.
* Clean and user-friendly dashboard design.
* Data visualization for quick decision-making.
* Drill-down and interactive reporting where applicable.

### Tools & Technologies

**Microsoft Power BI | Power Query | DAX | Excel | Data Cleaning | Data Visualization**

### Outcome

The project provided a **centralized and interactive healthcare reporting dashboard** that converts raw data into meaningful visual insights. It helped demonstrate practical knowledge of **data cleaning, data transformation, Power BI, DAX, KPI creation, data visualization, and analytical reporting**.
